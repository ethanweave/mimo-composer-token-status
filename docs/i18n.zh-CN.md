# i18n（zh-CN）

默认界面文案（与 SPEC 一致）。

| 键 | 文案 |
|----|------|
| `status.strip` | `缓存 {cache}% · 剩余 {remaining}%` |
| `status.cache` | `缓存` |
| `status.remaining` | `剩余` |
| `status.empty` | `—` |
| `status.a11y` | `缓存命中 {cache}%，剩余 {remaining}%` |
| `status.tooltip.remaining` | `剩余上下文预算（与输入区上下文环同源）` |
| `status.tooltip.cache` | `本会话缓存读命中率` |

## 数值

- 均为整数百分比，四舍五入。  
- 不出现小数。  
- 无数据时用空态，不写 `0% · 0%`（除非真实即为 0 且宿主选择显示）。

## 标点

- 两项之间使用中点 ` · `（U+00B7 + 左右空格）。
